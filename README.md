# Loopstudios Landing Page

A responsive landing page for Loopstudios, built with HTML and CSS.

## Project Overview

This project recreates a modern, visually rich landing page featuring:

- A full-width hero section with navigation and branding
- A split feature/about section
- A creative gallery of immersive experience cards
- A footer with navigation and social links
- Mobile-responsive layout styling

## Tech Stack

- HTML5
- CSS3
- Google Fonts

## Files

- index.html — page structure and content
- style.css — visual design and responsive styling
- images/ — desktop and mobile project assets

## Run Locally

1. Open the project folder in your editor.
2. Launch index.html in a browser, or use a local preview extension.

## Design Reference

This page is inspired by the Loopstudios landing page design and follows a clean, editorial-style aesthetic.
